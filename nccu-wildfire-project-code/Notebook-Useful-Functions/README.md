This folder contains a variety of functions that I have found to be useful given certain limitations on NC Share. 
ChartMaker
-Create Charts (duh).

CoordFromShp
- Generate the coordinates from a given .shp file.

CoordsOnAShapefile
- Generate a red dot on a .shp file associated with some coordinate.

CoordsOnATifFile
- Generate a red dot on a .tif file associated with some coordinate.

MeasureLength&WidthFromShpFile
- Retrieve the length and width of a .shp file as KM.

Unzip Function
- As the name implies, unzip function to unzip .zip files on NC Share or some other remote desktop which may not have this function integrated.
